# Blackjack Tracker

A personal blackjack session tracker that runs as an installable web app.

- Plan a session (one buy-in, fixed bet, pocket rule), run it at the table, review it afterwards.
- Stats: running total, luck against the house edge, breakdowns, discipline streak.
- All data stays on the device (browser storage). Use Settings > Copy a backup to export it.

## Install on iPhone
Open the site in Safari, tap Share, then "Add to Home Screen".

## Files
- `index.html`: the whole app (no build step).
- `sw.js`, `manifest.webmanifest`, icons: offline support and home-screen install.
